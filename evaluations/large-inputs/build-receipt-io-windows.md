# Windowsでのビルド・チェッカー証跡のI/O比較

WindowsのPowerShellで、MoCAの既存のPythonから実行する。対照と候補を分離した作業ツリーに置き、同じ試験スクリプトに各ツリーの `src` を指定する。

```powershell
$env:PYTHONPATH = '<対照または候補のツリー>\src'
python -B evaluations/large-inputs/build_receipt_io.py
```

C# 800件×20,000 B、合成.NET 9参照256件×64 KiB、成果物152件、合成チェッカーを一時フォルダに作る。ビルド前後の入力、増分成果物、成果物の証跡保存、チェッカー単独再開と検証ファイルを順に照合する。通常時間は温めた後の1回、Pythonの `stat`・`lstat`・`scandir`、SHA-256生成回数、読み取りオープンと論理読込量は別の1回で数える。これらはOS全体の呼び出しや物理ディスク読込量ではない。停止応答は合成スレッドが停止フラグをセットしてからキャンセルを捕捉するまで。業務PHP/C#、.NETビルド、チェッカー、DB、Junieは起動しない。

## 元のWindows計測

Windows 11 / Python 3.13.17、基準 `91074035`。同じ合成入力を温め、別プロセスで対照→候補→候補→対照の順で実施した。合計の証跡照合は対照 3,703.42 / 2,828.63 ms、候補 3,334.20 / 2,655.62 ms。Pythonの `stat` は7,370→3,740回、SHA-256計算は3,650回で同じ。証跡の指紋とSHA-256に渡した総バイト数も一致した。時間を測る回とカウンターは別に実行。停止要求への応答は両版とも3 ms未満だった。対照と候補の所要時間の範囲は重なるため、実運用やCI全体の短縮を保証しない。

## 変えない検証境界

ファイルの通常属性を確認する際の重複と、列挙時・ハッシュ入力時の相対名の再計算だけを削減する。作業ツリー内の出力対象、除外、順序、内容ハッシュ、リンク拒否は維持する。過去の結果をキャッシュせず、別工程で照合を省かない。回帰では、保存済み証跡、同サイズ・同時刻の差し替え、照合中の成果物の消失／合成読込障害、停止要求、チェッカー単独再開の入力・成果物・参照変更を確認する。この検査はファイルシステム全体の原子的スナップショットを作るものではない。

## #318候補を含む同一ベースでの再確認

Windows 11 10.0.22000 / Python 3.13.17。対照 `beb6a02`（#330後のmain `f9f5784` を元に準備した #318 最終候補）、#319候補 `84b6f4a`。同じスクリプトで対照→候補→候補→対照の順に各2回実行した。

| 工程（ms） | 対照2回 | 候補2回 |
| --- | ---: | ---: |
| ビルド前の入力 | 864.93 / 2334.71 | 818.50 / 858.66 |
| 増分成果物の照合 | 111.10 / 324.47 | 106.65 / 120.18 |
| ビルド後の入力 | 857.71 / 1372.57 | 792.22 / 779.72 |

| チェッカー検証ファイル | 7.61 / 12.77 | 7.08 / 7.73 |
| 合計 | 2951.54 / 6289.34 | 2664.60 / 2766.78 |

4回の照合結果はすべて同じ指紋 `5c361cb0873c58f3b037ddef9a2fa51d8fe993eaab6fd04a944a8be5860a2299`。列挙81回、読み取りオープン3,641回、論理読込121,466,717 B、SHA-256生成3,650回は全回同一で、Pythonが観測する `stat` の呼び出しだけ7,370→3,740回（約49%減少）だった。対照後半の時間のばらつきは未切り分け。停止応答は対照0.26–8.20 ms、候補0.37–12.52 msで、改善は確認していない。

Windows実機の対象9件（ビルド証跡・チェッカー単独再開）は8成功、ファイル・シンボリックリンク作成権限不足（WinError 1314）の1件をスキップ、失敗なし。macOSの補助確認ではリンク拒否を含むビルド証跡8件が成功。Windows 3.11、候補のGitHub全CI、実プロジェクトや実SDKビルドの時間は未検証。
