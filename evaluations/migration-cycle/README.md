# 移行・ビルド・テスト・チェッカーのサイクル改善

2026-11-17、macOS、Junie 26.11.1（4020.10、Junie Lite）、.NET SDK 10.0.201で実施。改善前 `f5de2af` を1回、改善後を2回、通常のダッシュボード経路で実行した。ACPにモデルがなく、画面の「今回のみ非対話モードで再試行」で実際のJunie `--task` を起動した。

## 変更

- 移行では現在のカプセル・境界資料・追加指示、修正では全原文カプセル・元の診断・追加指示を、JSON化後24,000 UTF-8バイト以内なら必須ルールとまとめてガイドラインファイルで渡す。ファイル読み込みの往復を減らし、Windowsの引数長制限を避ける。現行の移行先は毎回読む。
- 入力が上限を超える場合は一部を省略せず、全ファイルの参照へ戻す。元の入力と診断ログは保持する。
- 対応形式の指摘が前回の同じ工程から厳密に減り、新しい指摘を含まない場合は、残り回数内で修正を続ける。同じ集合の繰り返し、解消済み指摘の再発、残った指摘と新しい指摘の混在は停止する。JSON・自由記述の件数は推測せず、同じ診断の繰り返しで止める。
- ビルド・テスト・チェッカーを修正後も毎回実行する。修正上限、対象外ファイルの変更検出、手修正との競合検出、人の確認からの再開は維持する。

## 固定ケースと精度

PHPは27行・24個の値、2カプセル、必須ルール4ファイル、指定定数8個、隣接フォルダのヘルパー2個。改善前後で同じアプリ・設定を使用し、原文カプセル2件のSHA-256一致を確認した。移行完了後のスクリプトで `Rule1Start` のセミコロンを削除し、`Rule4End` の値を壊した。操作待ちの許可以外に人の修正指示は与えていない。

全3試行でビルドが一度失敗し、実際のJunieが自動修正した。改善前・改善後1回目はビルド修正時に両方直り、改善後2回目はビルド修正後に残った指摘をチェッカー修正で直した。最後のビルド・チェッカー終了コードはすべて0。

`after_build` のテストで24件の値と順序の完全一致を確認し、独自チェッカーで同じ値・指定定数8個・ヘルパー2個の利用を確認した。ビルド済みバイナリを `dotnet run --no-build` で検査するため、検査内の重複ビルドはない。確認対象はこの固定ケースであり、AIの移行精度全般の保証ではない。

改善後2回の平均でJunie処理時間は約17%、入力合計は約21%、ツール操作数は約31%減った。入力合計にはキャッシュ読み込みが含まれ、課金額の削減率ではない。修正回数やモデル応答にはばらつきがあり、2回目の全体時間は改善前より長かった。

Junie処理時間は、今回の完了トークンに一致する各セッションの `TaskStartedEvent` から最終イベントまでの時間を合算した。起動・信頼確認・ビルド・テスト・チェッカー時間を含まない。全体の経過時間はそれらも含む。ツール操作数は `ToolBlockUpdatedEvent` の異なる `stepId` 数。工程別・キャッシュ内訳・Run IDは[計測データ](results.json)に保存している。

追加確認として、改善後1回目の移行先の `Rule4End` だけを再度壊し、画面の「ビルド・チェックを再実行」を選択した。同じRunでチェッカー修正を1回行い、再ビルド・テスト・チェッカーが成功した。この追加実行は上の速度比較に含めていない。

回帰テストでは、指摘が減る場合の継続、回数上限、停滞・再発・混在時の停止、自由記述の診断・証明できない履歴の拒否、テスト失敗時のチェッカー抑止も確認する。入力の検査にはUTF-8・CRLF保持、JSONのエスケープ後の容量、上限超過時の全文参照、古い入力の除去、シンボリックリンク拒否、元の出力と追加指示の併用・手修正の保持を含む。

計測は `f5de2af` に本変更を適用して実施した。最後にエディタ改修 `444dd01` を取り込んだ状態で回帰テスト234件を実行し、232件成功・環境条件で2件スキップ、失敗なし。Windows実機を必要とする検査は今回実行していない。

## 再現

```sh
python evaluations/migration-cycle/create_fixture.py
php-to-csharp-harness dashboard --config <表示されたフォルダ>/harness.toml
```

開いた画面の「実行」で `common-rules-context` を選び、実行する。

生成・編集は新しい一時フォルダ内に限定する。Junieが2つの不具合をまとめて直すか、別の試行で直すかは固定していない。Windows実機、大規模な原文、外部サービスに依存するチェッカーの速度は今回の計測対象外。
