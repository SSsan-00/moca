# Windowsで移行ハーネスを設定する

ハーネスのチェックアウトから `docs/windows-user-guide.md` と `harness.example.toml` を読み、利用者の案件に合わせた設定案と次の画面操作を案内する。既存の `harness.local.toml` があれば、その内容に沿って必要な変更箇所を示す。

1. アプリのGitリポジトリ、移行元PHP、書き換えるC#やRazor、ビルド対象を確認する。ルールや独自スクリプトがある場合は、ファイルと起動方法を確認する。
2. ダッシュボードの **移行単位** で移行元と移行先を設定する。プロジェクト共通のルールと実装例は **移行ルールを追加** と **参考実装ペアを追加** から設定する。ルールと共通資料は行範囲を省略すると全文が渡る。**ビルド・独自チェッカー** ではビルド対象を指定し、チェッカーは1行目に実行ファイル、2行目以降に引数を入力する。自動修正回数の空欄は2回、0は自動修正なしとして案内する。
3. PHPとルールは準備時のアプリフォルダから読み込まれ、ビルドとチェッカーは基準コミットから作るworktreeで動く。リポジトリと保存先、基準リビジョン、Junieの上限、ビルドとチェッカー、差分ビューアーは **プロジェクトの詳細設定** にある。初回の準備、実行、中断後の再開をダッシュボードの表示に合わせて案内する。
4. 自作スクリプトがある場合は、**スクリプトを追加** から実行工程を選び、実行ファイルと引数を1行に1つずつ入力するよう案内する。準備前はアプリのリポジトリ、他の工程ではRunの作業ツリーで動く。

このスキルはWindowsでの操作を案内する。移行実行中の案件固有ルールは設定ファイルの `[[project.migration_rules]]` から渡す。
