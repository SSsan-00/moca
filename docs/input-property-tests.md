# 入力境界のプロパティテスト

本番のファイルを使わず、決まったシードから作った小さな合成データで検証します。既存の回帰テストを補うもので、PHP、移行後のアプリ、ビルド、チェッカー、Junie、モデルサービスは起動しません。追加の開発・実行時依存はありません。

| 対象 | シード | 確認する性質 |
| --- | --- | --- |
| PHPの固定・カプセル分割 | 314100～314105 | UTF-8、BOM付きUTF-8、EUC-JPの固定バイト列とハッシュを元ファイル変更後も保持する。括弧・引用符・混在改行・長行を含む範囲から本文を再構成し、各文字を欠落・重複なく担当範囲に割り振り、表示用の重なりと文字数予算を守る。未閉鎖ブロックは字句解析で関数として確定せず、本文は欠落しない。 |
| TOML | 314200～314205 | 日本語の移行単位と設定値を正しく読み、型違い・重複キー・重複IDを拒否する。読み取り前後で構成ファイルのバイト列を保つ。 |
| ACPの表示用更新 | 314300～314305 | UTF-8、BOM付きUTF-8、CP932で表示テキストの順序と繰り返しを保つ。表示内容のない通知や、途中で切れたJSON・配列が完了、許可要求、外向きの送信を発生させない。 |
| チェッカー出力 | 314400～314405、314450～314455 | UTF-8、BOM付きUTF-8、CP932の指摘を保持する。欠落した指摘、未実行、未知形式、合格文と別情報の混在は成功扱いしない。入力判定の65,536バイト境界を別途検証する。 |
| 旧Runと不完全なRun記録 | 314500～314505 | 版番号なしの正常な記録で値と補足情報を保持する。途中で切れたJSON・型違い・重複キーを拒否し、正常・異常ともに保存済みのバイト列を変更しない。 |

Windowsのリポジトリルートで再現できます。

```powershell
python -m unittest discover -s tests -p "test_input_properties.py" -v
python -m unittest discover -s tests -p "test_input_properties.py" -k test_php_capsules -v
```

失敗の表示にはシードと、文字コード・データの種類・予算などそのケースの条件が出ます。同じPythonで対象テストを再実行すると同じ入力を再生成できます。最小化する場合は該当シードを残し、テスト内の入力生成の行数や反復数を減らしてください。

通常CIのWindows版unittestで自動実行する6テスト、122サブケースです。各生成器は6シード、PHPは8行、チェッカー出力は最大65,537バイトに固定し、追加のCIジョブは設けません。全入力や実運用についての安全性を保証する検査ではありません。
